# Felys Changelog

## [2.0.0] - 2026-09-04

### Major Architecture & Upgrades
- **Atomic Multi-Account Ledger**: Full ACID double-entry audit logging for financial accounts.
- **Predictive Cash Runway**: Intelligent burn rate simulator and deadline-linked spending advice.
- **Deterministic Fio AI Skills**: Offline-first instant answers for *Can I Spend?*, task prioritization, and saving simulation.
- **High-Fidelity Visual Design**: Upgraded banking assets, glassmorphism UI, smooth momentum scroll, and full PWA onboarding.
- **Automated Verification**: Vitest unit testing suites, GitHub Actions CI workflow, and Vercel Cron handlers.
